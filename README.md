# Мария Новикова — сайт-CV

Адаптивный одностраничный сайт в IT-стиле: графитовый фон, лаймовые акценты, проекты и измеримые результаты.

## Открыть сайт

Скачайте `index.html` и откройте его в браузере. Установка пакетов и сборка не нужны. Стили и небольшой скрипт навигации включены в файл; внешних зависимостей нет.

## Редактирование

- **О себе:** найдите `section id="about"`. Замените заголовок и абзац внутри `class="placeholder"` своим текстом. Подсказку `[ МЕСТО ДЛЯ ВАШЕЙ ИСТОРИИ ]` можно убрать.
- **Опыт:** раздел `section id="experience"`.
- **Навыки:** раздел `section id="skills"`.
- **Образование:** раздел `section id="education"`.
- **Контакты:** раздел `section id="contact"`; Telegram также указан в первом экране.
- **Цвета:** переменные в блоке `:root` внутри `<style>`.

Даты двух ролей в Сбере оставлены одинаковыми согласно исходному CV: декабрь 2024 — январь 2026. Проверьте их перед отправкой резюме.

## Публикация

Исходники сохранены в приватном репозитории. Загрузка файлов сама по себе не включает GitHub Pages.

Если GitHub Pages доступен для вашего репозитория и тарифа:

1. Откройте Settings → Pages.
2. Выберите Deploy from a branch.
3. Укажите ветку `main` и папку `/ (root)`, сохраните настройки.
4. Дождитесь публикации и используйте адрес, показанный GitHub в разделе Pages.

Если Pages недоступен для приватного репозитория, можно использовать другой статический хостинг, поддерживающий приватные GitHub-репозитории. Видимость репозитория автоматически не изменялась.

Сайт содержит телефон и email из CV; после публичной публикации они будут видны посетителям.

## Проверки

Проверены уникальность HTML id, внутренние якорные ссылки и наличие основных показателей и контактов. Вёрстка содержит адаптивные правила, состояния клавиатурного фокуса, поддержку reduced motion и стили печати. Визуальная проверка в браузере не выполнялась.
